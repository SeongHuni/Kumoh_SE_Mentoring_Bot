## 읽기 전에

- 이 목록은 여러 대학에서 실제로 다뤄진 질문 **유형**을 모아 검색하기 쉬운 말로 패러프레이즈한 것이다. 특정 대학 학생의 실제 문장을 그대로 수집한 설문이나 빈도 통계는 아니다.
- `[FAQ]`는 공식 FAQ·Q&A에서 질문을 직접 확인한 항목이고, `[안내]`는 공식 학사·졸업·프로그램 안내의 내용을 학생 질문 형태로 정규화한 항목이다.
- 학점, 신청 기간, 휴학, 졸업, 장학 기준은 대학·학번·학년도마다 달라진다. 챗봇 답변으로 사용하려면 반드시 소속 대학의 최신 학칙과 공지를 다시 확인해야 한다.
- 일부 공식 FAQ는 오래된 질문 수요를 보여 주기 위해 포함했다. 특히 서경대학교와 동아대학교의 일부 자료는 2021학년도 기준 또는 2021년 게시 자료이고, 숭실대학교 유고결석 자료는 2018년 게시 자료다.
- 이 문서는 조사 참고 자료이며 `data/raw/posts.json`, Chroma DB 또는 현재 허용된 수집 범위에 자동 편입하지 않는다.

## 활용 권장 방식

1. 챗봇 평가 질문으로 쓸 때는 학교명·학번·학년·학기 같은 슬롯을 분리한다.
2. 답변이 학칙에 좌우되는 질문은 `최신 공지 확인 필요` 의도로 별도 분류한다.
3. 한 질문에 여러 의도가 섞인 경우 수강, 학적, 졸업, 취업처럼 단일 의도로 다시 나눈다.
4. 실제 금오공대 답변 데이터로 만들기 전에는 금오공대 공식 최신 문서와 하나씩 대조한다.
5. 공식 답변 근거가 없는 질문은 FAQ 후보로만 유지하고 생성형 답변의 근거 문서로 사용하지 않는다.
