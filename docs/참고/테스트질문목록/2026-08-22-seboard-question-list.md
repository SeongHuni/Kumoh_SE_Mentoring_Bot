# SE Board 기반 소프트웨어전공 질문 목록

- 조사일: 2026-08-22
- 대상: [SE Board](https://seboard.site/)의 공개 공지, 정보 게시글, Project & Job, SE 건의사항, 2026 홈커밍데이 Q&A
- 수집 결과: 7개 범주, 질문 후보 127개, 공개 출처 15개
- 용도: 금오공과대학교 컴퓨터공학과 소프트웨어전공 멘토링 챗봇의 질문 후보, 의도 분류, 평가 데이터 설계 참고

## 읽기 전에

- 이 문서는 SE Board에서 확인한 질문 **후보 목록**이며 공식 답변집이나 질문 빈도 통계가 아니다.
- `[실제질문]`은 공개 Q&A 또는 게시글·댓글에 실제로 나온 질문을 가볍게 정규화한 항목이다.
- `[본문기반]`은 공개 공지·모집글의 상세 내용을 학생 질문으로 바꾼 항목이고, `[목록기반]`은 게시글 제목까지만 근거로 삼은 항목이다.
- `[기능후보]`는 공개 화면의 메뉴·검색·필터에서 도출한 사용 질문이다. 로그인 후 정책이나 실제 동작까지 확인했다는 뜻은 아니다.
- `[건의기반]`은 공개 건의사항 제목에서 도출했다. 해당 오류가 현재도 존재한다고 단정하지 않는다.
- `SB03`은 제목에 `Archive`가 붙은 과거 졸업 안내다. 학점, 졸업, 수강, 일정에 관한 답변을 만들 때는 최신 공식 공지와 학사 시스템을 다시 확인해야 한다.
- 사이트의 robots 정책을 보수적으로 적용해 자동 크롤링하지 않고 공개 화면을 수동 점검했다. 로그인 전용 영역, 자유게시판의 유머·사담, 작성자 식별정보, 연락처, 자격증명은 수집하지 않았다.
- 이 문서는 조사 참고 자료이며 `data/raw/posts.json`, Chroma DB 또는 운영 인덱스에 자동 편입하지 않는다.
